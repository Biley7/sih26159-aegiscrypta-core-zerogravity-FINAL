## Executive Summary

- **Issues:** 0 P0, 11 P1, 10 P2, 1 P3.

## 5. Other Verified Audit Findings

- [ ] **Settings fields rely on placeholders instead of associated labels. [P2]** The endpoint and API-key inputs have placeholders but no `<label>` / `htmlFor`; placeholder text is not a robust persistent accessible name. See [SettingsModal.tsx](frontend/src/components/SettingsModal.tsx#L191), [SettingsModal.tsx](frontend/src/components/SettingsModal.tsx#L245).
- [ ] **Clickable AI node is a non-semantic `div`. [P2]** It has `onClick` and `cursor-pointer` but no `role`, `tabIndex`, keyboard handler, or button semantics. See [ThreatCenter.tsx](frontend/src/components/ThreatCenter.tsx#L339).
- [ ] **Terminal resize is mouse-only. [P2]** Resize starts from `React.MouseEvent` and `onMouseDown`; there is no pointer/touch path or touch-specific handling. See [App.tsx](frontend/src/App.tsx#L234), [DockedTerminal.tsx](frontend/src/components/DockedTerminal.tsx#L136).
- [ ] **Detector performance warning. [P2]** The bundled detector returned `layout-transition` at [styles.css](frontend/src/styles.css#L1131): `transition: width 0.3s ease`. Width transitions can cause layout work during bar animation; use a transform-based fill or otherwise bound the layout animation.
- [ ] **Reduced-motion alternative not found in searched stylesheet. [P2]** The source scan found no `prefers-reduced-motion` rule while the UI uses pulse/spin and transition animation utilities. Preserve state feedback while disabling nonessential motion for reduced-motion users.

## Positive Findings

- Axios consistently centralizes API requests, including scan, health, PCAP, and report endpoints; the shared key is applied centrally rather than duplicated per call.
- The user-configured API URL is persisted and applied to the shared Axios client.
- App owns a nullable typed `ScanResponse`; the primary protocol, report, and threat components can consume the real response, and several supporting cards derive check state from backend results.
- Responsive dashboard column breakpoints and mobile navigation are present.
- Global `:focus-visible` styling exists in [styles.css](frontend/src/styles.css#L174); design tokens and separate light/high-contrast CSS variables also exist, though utility classes are inconsistent.
